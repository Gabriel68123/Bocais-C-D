# Bocais-C-D
Este projeto é uma ferramenta web interativa desenvolvida em Python e Streamlit para análise e visualização em tempo real de escoamentos compressíveis permissíveis unidimensionais (1D) em bocais Convergentes-Divergentes (C-D / De Laval).
